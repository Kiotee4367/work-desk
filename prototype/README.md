# Design reference

Put `WorkDashboard.jsx` in this folder. It is the design reference the build follows for
screen layout, wording, the BRANDS values, the TOUR steps and the prompts.

It was not included when Phase 1 was built, so the brand values in `config/brands.ts` and
the wording on the screens are stand-ins. Once the file is here, ask Claude Code to
"reconcile the app with the prototype" and it will update them.
